# Support

Read the [documentation](docs/index.md), then use the
[issue tracker](https://github.com/altophp/scale/issues) for questions or bug reports.

Include the PHP and package versions, scale type and parameters, input values,
expected steps or output, and actual result. A complete short PHP example makes
rounding, tolerance, and domain issues easier to reproduce. For inferred scales,
include the original positive dataset and guessing tolerance.

For a feature request, describe the progression or design task and the result
you need, including any current workaround.
